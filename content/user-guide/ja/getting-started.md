Sona を初めて起動する場合、この手順がローカル文字起こし環境を整える最短ルートです。

## 推奨対象

- 初回デスクトップ版インストール
- 手動でモデルを選ぶ代わりに推奨オフライン構成をすぐに使いたいユーザー
- できるだけ早く `Live Record` を試したいユーザー

## 開始する前に

- お使いの環境で Sona が正常に起動できること。
- 初回設定で推奨モデルパックをダウンロードするため、インターネット接続を維持してください。

## デスクトップ版のインストール

1. [Sona Downloads](/downloads) を開き、お使いの OS に適したビルドを選択します。ダウンロード詳細が取得できない場合は、[GitHub Releases](https://github.com/AirSodaz/sona/releases/latest) をご利用ください。
2. アプリを起動します。
3. ソースからビルドする場合は、[プロジェクト README](readme) を参照してください。

Windows SmartScreen、macOS Gatekeeper、または Linux の実行権限ダイアログが表示された場合は、インストーラーが Sona Downloads または GitHub Releases から入手したものであることを確認し、OS の案内に従って実行を許可してください。システム全体のセキュリティ保護を無効化する必要はありません。

## `初回セットアップ` を完了する

1. Sona の起動時に `初回セットアップ`（First Run Setup）画面が表示されるのを待ちます。
2. ウェルカム画面を確認します。Sona が推奨する最短ルートは `マイク設定 -> Live Record` です。
3. `次へ`（Continue）をクリックします。
4. モデル選択ステップで `推奨モデルをダウンロード`（Download Recommended Models）をクリックします。必要なモデルが既に存在する場合は `次へ` が表示されます。
5. 推奨オフラインモデルのダウンロードと解凍が完了するまで待ちます。
6. マイク設定ステップへ進み、マイクへのアクセスを許可します。
7. マイクの権限が拒否された場合は、OS のセキュリティ設定を修正した後に `権限を再試行`（Try Permission Again）をクリックします。
8. Sona の `Live Record` で使用するマイクを選択します。
9. `Live Record を開始`（Start with Live Record）をクリックします。

## 完了後に起きること

- Sona はローカル文字起こしに必要な推奨オフライン構成を適用します。
- アプリが `Live Record` 画面で開きます。
- セットアップが未完了の場合、ホーム画面のリマインダーバナーからいつでも再開できます。

## セットアップ後のおすすめステップ

- すぐに音声を録音・文字起こししたい場合は、直接 [Live Record](guide:live-record) を開きます。
- 既に文字起こししたいファイルがある場合は、[Batch Import](guide:batch-import) を開きます。
- セットアップが繰り返し表示される場合やモデルが見つからない場合は、[FAQ とトラブルシューティング](guide:faq) を確認してください。

## 補足事項

- 初回セットアップ中に `あとで`（Later）をクリックしてスキップし、後からバナー経由で再開できます。
- リマインダーバナーを非表示にすると、セットアップが完了するまでホーム画面に再表示されなくなります。
- モデル設定は後からいつでも `Settings > Model Settings` で変更できます。
- 既定のマイクは後から `Settings > Input Device` で変更できます。
- モデルのダウンロードが進まない場合は、インターネット接続とモデル配布ホストへのアクセスを確認し、初回セットアップを再試行してください。それでも解決しない場合は、`Settings > Model Settings` で手動ダウンロードまたは選択を行い、`Settings > General > Diagnostics` で診断情報を確認してください。
- スタンドアロン CLI によるローカル/オンラインのファイル・リアルタイム文字起こし、モデル管理、エクスポート、診断、またはローカル API サーバーを利用したい場合は、サイト内の [CLI ガイド](guide:cli-guide) を参照してください。
