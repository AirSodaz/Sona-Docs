Sona が文字起こしセグメントを作成した後は、エディタが内容の確認、修正、タイムスタンプによるナビゲーション、話者ラベルの確認、そして大規模な書き換えからの復元を行う中心の場所となります。

## 推奨対象

- セグメントごとの文言確認
- 文字起こしテキストと元の音声タイミングの相互ジャンプ
- エクスポート前の話者ラベルの修正
- LLM Polish、翻訳、再文字起こし後の `Version Snapshots` の比較
- エクスポート前の検索、結合、削除、または簡易フォーマット調整

## 開始する前に

- [Live Record](guide:live-record)、[Batch Import](guide:batch-import)、または [プロジェクトと Inbox](guide:workspace-projects-and-inbox) から文字起こしを開きます。

## 文字起こしセグメントを確認・編集する

1. エディタ内のセグメント一覧を確認します。
2. タイムスタンプをクリックすると、その時点の音声位置へジャンプします。
3. セグメントテキストをダブルクリックするか、編集アクションを使用して編集モードに入ります。
4. 読み取り専用セグメントを右クリックすると `Copy` と `Select All`、編集中に右クリックすると `Cut`、`Copy`、`Paste`、`Select All`、`Bold`、`Italic`、`Underline`、`Strikethrough`、`Inline Code` を利用できます。キーボードのコンテキストメニューキーまたは `Shift + F10` でも同じメニューが開きます。
5. `Enter` を押すと現在のセグメントを保存します。
6. `Shift + Enter` を押すとカーソル位置で現在のセグメントを分割します。
7. 結合アクションを使用してセグメントを次のセグメントと統合します。
8. 削除アクションを使用して確認後にセグメントを削除します。

## 話者ラベルを確認する

1. セグメントに話者バッジがある場合、バッジをクリックして話者グループ全体を `Speaker Profile` に割り当てます。
2. 同じメニューからグローバルプロファイルの展開や、そのグループの匿名ラベルへのリセットを行えます。
3. エクスポート前に集中して話者をチェックしたい場合は、文字起こしヘッダーから `Speaker Review` を開きます。
4. `Needs review`、`Suggestions`、`Anonymous`、`Identified`、`Reviewed`、または `All` で絞り込みます。
5. 各グループの先頭セグメントをプレビューし、一致する先頭セグメントへジャンプ、現在のラベルの確認、提案された候補の適用、別のプロファイルの割り当て、または匿名へのリセットを実行します。

## Version Snapshots を使う

1. 文字起こしが保存済みのプロジェクト項目（Draft 以外）である場合、ヘッダーから `Version Snapshots` を開きます。
2. `LLM Polish`、`Translate`、`Re-transcribe` など一括書き換え操作の前に保存されたスナップショットを選択します。
3. スナップショットと現在の文字起こしを比較します。
4. 書き換えの一部のみを戻したい場合は、選択した変更行を復元します。
5. 書き換え全体を破棄したい場合は、文字起こし全体を元に戻します。

## 検索と再生コントロール

1. `Ctrl + F` を押して文字起こし内を検索します。
2. 音声ファイルが利用可能な場合は、オーディオプレイヤーを使用して再生、一時停止、シーク、速度変更、音量調整を行います。
3. エディタから離れることなく、一致するセグメント間をジャンプします。

## エディタ内で維持される状態

- 文字起こしはセグメント単位で編集可能です。
- 話者の修正は表示中の 1 つのセグメントだけでなく、話者グループ全体に適用されます。
- 再生位置と文字起こしナビゲーションはタイムスタンプを通じて同期されます。
- `Version Snapshots` からの復元時にも現在の文字起こしが先に保存されるため、ロールバック自体も可逆的です。
- エディタツールバーは、セグメントの編集時のみアクティブに表示されます。

## お役立ちメモ

- ツールバーおよびショートカットは、`元に戻す`、`やり直し`、`太字`、`斜体`、`下線`、`取り消し線`（`Ctrl + Shift + S`）、`インラインコード`、セグメント分割をサポートしています。
- `Speaker Profiles` は [語彙と詳細設定](guide:vocabulary-and-advanced-settings) で作成します。プロファイルは候補の提示や自動一致に役立ちますが、手動での確認も可能です。
- `Version Snapshots` は、下書き（Draft）や一時的な `current` 文字起こしではない、保存済みのプロジェクトアイテムにのみ表示されます。
- 編集後に LLM による整文や翻訳を追加したい場合は、[AI Polish と翻訳](guide:ai-polish-and-translate) に進んでください。
- エディタの周囲で保存済みアイテムを再度開いたり整理したりしたい場合は、[プロジェクトと Inbox](guide:workspace-projects-and-inbox) に進んでください。
- 作業が完了しファイルを出力したい場合は、[エクスポートと設定](guide:export-and-settings) に進んでください。
