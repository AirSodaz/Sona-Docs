這頁覆蓋工作流程的收尾部分：匯出成品、做最後的說話者與版本檢查、快速找到最常用設定的大致入口，以及理解 `儀表板`、`診斷`、`備份與復原`、`自動化` 和通知分別在哪裡。

## 如何匯出一份成稿

匯出前，如果交付或複核需要說話者標籤，請先從轉錄標題列打開 `說話者校對`。對於已儲存且非草稿的轉錄，如果需要復原部分差異或整份回退一次批次改寫，請先打開 `版本快照`。

1. 點擊頂部列中的 `匯出` 按鈕。
2. 在 `匯出轉錄` 彈出視窗中填寫 `檔案名`。
3. 選擇 `匯出目錄`。
4. 選擇輸出格式： `SubRip (.srt)`、`WebVTT (.vtt)`、`JSON (.json)`、`Plain Text (.txt)`、`Markdown (.md)`。
5. 選擇匯出模式： `原文`、`譯文`、`雙語`。
6. 點擊 `匯出`。
7. 如果只想依目前匯出模式複製純文字，可以使用 `複製到剪貼簿`，不必寫出檔案。

## 匯出之後會得到什麼

- Sona 會把轉錄內容寫入您選擇的路徑和格式。
- `Markdown (.md)` 會把說話者標籤保留為粗體標籤，方便在 Markdown 編輯器中閱讀。
- 如果目前已有譯文，可以匯出純譯文或雙語版本。
- `複製到剪貼簿` 會使用目前選擇的匯出模式，並複製最終分段裡的純文字。
- `譯文` 與 `雙語` 只有在至少一個分段已經帶有翻譯文字時才會出現。

## 什麼時候該回到 `專案中心`

- 如果您要重新打開、重新命名、移動或整理已經儲存的錄音和匯入內容，請回到 [專案中心與收件匣](guide:workspace-projects-and-inbox)。
- 現在專案上下文和 `Inbox` 組織也都統一放在 `專案中心`。

## 按分類組織的設定項

Sona 桌面端的設定側邊欄被劃分為 5 個分組：

### 1. 一般 (General)
- `設定 > 常規`：主題、介面語言、字型、開機自啟、靜默啟動（啟動最小化到系統匣）、更新檢查，以及 `診斷` 與 `備份與復原`
- `設定 > 儀表板`：全域內容概覽、說話者覆蓋率與 LLM 使用趨勢
- `設定 > 關於`：版本資訊、版本說明、開源授權與更新檢查

### 2. 辨識與語音 (Recognition & Speech)
- `設定 > 輸入裝置`：麥克風選擇、系統音訊裝置選擇、麥克風增強、`保持麥克風啟用`、錄音時靜音
- `設定 > 字幕設定`：即時字幕浮動視窗行為、外觀樣式、滑鼠穿透與字級大小
- `設定 > 語音輸入法`：啟用 `語音輸入法`、全域快速鍵、`按住說話` / `切換模式`、情境預設與就緒狀態
- `設定 > 模型設定`：`即時錄音模型`、`批次轉錄模型`、CTC 強制對齊、說話者分離敏感度、`批次 VAD 分割`、`VAD Buffer Size` 與模型管理
- `設定 > 詞彙`：劃分為 `辨識與糾偏`、`提示詞與上下文`、`說話者檔案` 三個子標籤頁，支援統一詞典（視覺化與 YAML 原始碼雙模式）

### 3. AI 與自動化 (AI & Automation)
- `設定 > LLM 服務`：功能模型繫結（支援基於 llama.cpp 的本機 GGUF 模型與基於 aimux 的雲端多模型）、思考過程與正文分離、Provider 憑證管理
- `設定 > 自動化`：監控資料夾規則，可在 Sona 執行時自動轉錄、潤飾、翻譯並匯出新媒體檔案到指定專案

### 4. 整合與同步 (Integration & Sync)
- `設定 > 雲端同步`：端到端加密（E2EE）跨裝置同步庫，支援 WebDAV 與 S3 相容物件儲存（AWS S3、Cloudflare R2、MinIO 等）、主密碼、應急復原金鑰與衝突中心
- `設定 > API 服務`：本機 HTTP API 主機、連接埠、可選 API Key、IP 白名單、REST 轉寫與 WebSocket 即時串流辨識
- `設定 > MCP 服務`：Model Context Protocol 服務橋接設定、端點監控與 Agent 權限開關（允許文稿編輯、破壞性操作、模型管理等）

### 5. 系統與進階 (System & Advanced)
- `設定 > 儲存管理`：資料與模型目錄概覽、熱重載儲存遷移（無需重新啟動動態遷移目錄並帶進度提示）、純 Rust 音訊解碼與可選自訂 FFmpeg 路徑、磁碟分析與清理策略
- `設定 > 快速鍵`：即時錄音、播放、搜尋、專案導覽與編輯器快速鍵（支援刪除線 `Ctrl + Shift + S`）
## 診斷、備份、雲端同步與訊息中心

- 在 `設定 > 常規` 中，可以透過 `診斷` 檢查本機轉錄路徑、執行期就緒狀態和打包環境。
- 同一頁中的 `備份與復原` 可以匯出或匯入輕量歸檔，其中包含設定、專案資料、輕量歷史轉錄與摘要、自動化狀態，以及儀表板 LLM 使用記錄。
- 輕量備份會復原文字歷史和摘要，但不會包含原始音訊檔案；復原後的條目可能可以閱讀和編輯，但沒有音訊播放。
- `設定 > 雲端同步` 是獨立的端到端加密（E2EE）增量同步系統。文稿與設定離開本機前均由主密碼加密，支援應急復原金鑰重設存取，並提供衝突中心裁決多端並行修改。錄音音訊始終保存在本機機器上，不會上傳雲端。
- 頁面底部提供一次性匯入舊版 WebDAV 備份歸檔的入口；Sona 不再建立新的遠端整包備份。
- 頂部訊息中心集中管理批次轉錄、自動化與 LLM 任務，提供即時進度並在批次轉錄時支援即時取消，配備已完成任務清空選單；中斷的任務也可在其中的復原中心繼續或丟棄。
