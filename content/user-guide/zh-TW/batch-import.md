如果您已經有音訊或影片檔案，並且希望 Sona 在背景排隊處理，請使用 `批次轉錄`。

## 適合這些場景

- 錄好的會議、課堂、訪談或播客
- 需要從本機媒體檔案整理字幕
- 多個檔案需要連續排隊處理，而不是一次只做一個

## 入佇列前

- 先在 `設定 > 模型設定` 中設定 `批次轉錄模型`。
- 確認檔案屬於支援的音訊或影片格式。

## 把檔案加入佇列

1. 打開 `批次轉錄` 頁籤。
2. 將檔案拖入匯入區域，或者點擊 `選擇檔案`。
3. 把一個或多個檔案加入佇列。
4. 觀察佇列側欄和目前處理項狀態。
5. 如果還要繼續追加檔案，點擊 `新增更多檔案`。

## 處理過程中還能調整什麼

1. 點擊 `參數設定`，視需要調整 `字幕模式` 或 `語言`。
2. 透過 **總覽摘要面板** 掌握批次處理整體進度（總任務數、總時長、處理中、已完成與失敗統計），並可使用分組列表檢視清晰瀏覽。
3. 使用 **清空選單** 視需要清除已成功、已失敗或全部佇列項目。
4. **即時取消**：正在處理中的轉錄任務支援在佇列或頂部 `訊息中心` 中隨時觸發即時取消，並配有二次確認防誤觸對話框。

## 檔案完成後會發生什麼

- 已完成的檔案會載入主編輯器。
- 接下來可以繼續進入 [編輯與播放](guide:edit-and-playback)、[AI 潤飾與翻譯](guide:ai-polish-and-translate)、[專案中心與收件匣](guide:workspace-projects-and-inbox) 或 [匯出與設定](guide:export-and-settings)。

## 補充說明

- 如果沒有設定離線批次模型，Sona 會重新打開引導，而不是直接開始轉錄。支援使用 llama.cpp 引擎的 Qwen3-ASR 模型或 Whisper 系列高效完成批次任務。
- `設定 > 模型設定` 中的 `批次 VAD 分割`（基於升級的 Silero VAD v5）、`VAD Buffer Size` 與 `Max Concurrent Transcriptions` 會影響批次處理體驗。關閉批次 VAD 後，本機批次轉錄會整段辨識檔案。
- Sona 內建純 Rust 音訊解碼引擎，開箱即用支援 WAV、MP3、FLAC、OGG、AAC 與 M4A 常見格式，無需系統預裝 FFmpeg。如遇非常規專屬封裝或小眾編碼，可在 `設定 > 儲存管理` 中設定自訂 FFmpeg 路徑作為後備。
- 如果目標是從現成媒體檔案匯出字幕，`批次轉錄` 加匯出就是最直接的路徑。
