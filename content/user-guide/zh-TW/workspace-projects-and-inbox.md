如果您希望在不離開主編輯面的前提下整理已經儲存的錄音和匯入內容，就使用 `專案中心`（Projects）。

## 適合這些場景

- 不再把已儲存內容理解成獨立的歷史頁，而是統一在一個地方重新打開條目
- 在 `全部內容`、`收件匣`、專案與 `垃圾桶` 之間整理工作
- 為特定專案設定專屬流水線（熱詞、替換規則、提示詞預設、預設翻譯與潤飾），在開始新錄音或新匯入前先套用專案級預設值
- 復原誤刪的文稿或徹底清理垃圾桶

## 先理解四種瀏覽範圍

- `全部內容` 用來跨所有專案與收件匣總覽所有已儲存內容。
- `收件匣 (Inbox)` 用來承接尚未分配到專案的錄音和匯入內容。
- `專案` 提供聚焦後的獨立專案空間、專案級預設值與專屬流水線（熱詞/替換/提示詞繫結），以及針對新工作的快捷入口。頂部標題列也提供了全域專案快速切換器。
- `垃圾桶` 存放已刪除的內容，支援選取單個或批次復原，也可隨時徹底清空。

## 建立專案，或進入某個專案

1. 打開 `專案中心`（Projects）頁籤。
2. 使用左側邊欄在 `全部內容`、`收件匣`、個別專案與 `垃圾桶` 之間切換。
3. 如果您想為某個客戶、課程、會議系列或長期主題建立獨立空間，點擊 `新建專案`。
4. 輸入專案名稱，並視需要填寫簡短描述後建立。新專案建立時不會立刻帶自訂圖示。
5. 如果您希望新的錄音或匯入內容自動歸入某個專案，先在左側選取或透過頂部全域專案下拉選單切換到該專案，再開始 `即時錄音` 或 `批次轉錄`。

## 打開和整理已儲存條目

1. 點擊任意已儲存條目，即可在內建詳情面板中直接打開並繼續編輯，不必離開 `專案中心`。
2. 在專案上按右鍵，可以使用 `開啟` 或 `專案設定`；在已儲存條目上按右鍵，可以使用 `開啟`、`重新命名` 或 `刪除`。聚焦對應列後，鍵盤選單鍵或 `Shift + F10` 會開啟相同操作。
3. 使用搜尋、篩選、排序，以及 `清單檢視` / `網格檢視` / `表格檢視` 縮小目前瀏覽範圍。
4. 如果您要在 `Inbox` 與專案之間移動內容，或一次刪除多項內容，請先進入選擇模式。
5. 如果您想在保留目前專案上下文的前提下開始新工作，可以直接使用專案頂部的 `開始即時錄音` 或 `開啟批次匯入`。

## 調整 `專案設定` 與專屬流水線

1. 先打開某個專案，再點擊 `專案設定`。
2. 修改專案名稱和描述。
3. 如果需要，自訂專案圖示。專案圖示是在這裡修改的，不是在 `新建專案` 彈出視窗裡設定。
4. 設定該專案內工作的預設值： `預設摘要範本`、`預設翻譯語言`、`預設潤飾模式`、可選的 `預設潤飾上下文`，以及 `匯出檔案名前綴`。
5. **專案專屬流水線**：為專案單獨繫結或開關 `文字替換` 集合與 `熱詞` 集合。當該專案進行轉錄或後處理時，自動疊加這些規則。
6. 點擊 `儲存` 保留修改；如果點擊 `刪除專案`，專案本身會被移除，裡面的內容會回到 `收件匣 (Inbox)`。

## 垃圾桶與復原機制

1. 刪除的錄音或匯入條目不會立即從磁碟抹除，而是移入 `垃圾桶`。
2. 切換至 `垃圾桶` 範圍，可以檢視已刪除條目並點擊 `復原` 將其還原至原專案或 Inbox。
3. 點擊 `清空垃圾桶` 會永久清除其中的轉錄資料。

## 補充說明

- `全部內容` 適合跨專案瀏覽，但它不會替代目前專案的預設值。
- 當您不在任何專案內工作時，新的錄音和匯入內容會預設先進入 `收件匣 (Inbox)`。
- 即時錄音仍在進行時，這裡也可能先出現一個帶 `草稿` 標記的條目。停止錄音後，Sona 會直接把這條草稿完成為正式條目。
- 專案圖示支援系統圖示、推薦 emoji，以及自訂 emoji。
- 已儲存的錄音和匯入條目也支援在各自的重新命名流程中修改標題和圖示，但那與 `專案設定` 是兩套入口。
- 如果您在專案設定抽屜裡有未儲存變更，切換到別的瀏覽範圍前，Sona 會先詢問您是否放棄這些修改。
