如果你已经有音频或视频文件，并且希望 Sona 在后台排队处理，请使用 `批量转录`。

## 适合这些场景

- 录好的会议、课堂、访谈或播客
- 需要从本地媒体文件整理字幕
- 多个文件需要连续排队处理，而不是一次只做一个

## 入队前

- 先在 `设置 > 模型设置` 中配置 `批量转录模型`。
- 确认文件属于支持的音频或视频格式。

## 把文件加入队列

1. 打开 `批量转录` 页签。
2. 将文件拖入导入区域，或者点击 `选择文件`。
3. 把一个或多个文件加入队列。
4. 观察队列侧栏和当前处理项状态。
5. 如果还要继续追加文件，点击 `添加更多文件`。

## 处理过程中还能调整什么

1. 点击 `参数设置`，按需调整 `字幕模式` 或 `语言`。
2. 通过 **总览摘要面板** 掌握批处理整体进度（总任务数、总时长、处理中、已完成与失败统计），并可使用分组列表视图清晰浏览。
3. 使用 **清空菜单** 按需清除已成功、已失败或全部队列条目。
4. **实时取消**：正在处理中的转录任务支持在队列或顶部 `消息中心` 中随时触发实时取消，并配有二次确认防误触弹窗。

## 文件完成后会发生什么

- 已完成的文件会载入主编辑器。
- 接下来可以继续进入 [编辑与播放](guide:edit-and-playback)、[AI 润色与翻译](guide:ai-polish-and-translate)、[项目中心与收件箱](guide:workspace-projects-and-inbox) 或 [导出与设置](guide:export-and-settings)。

## 补充说明

- 如果没有配置离线批量模型，Sona 会重新打开引导，而不是直接开始转录。支持使用 llama.cpp 引擎的 Qwen3-ASR 模型或 Whisper 系列高效完成批量任务。
- `设置 > 模型设置` 中的 `批量 VAD 分割`（基于升级的 Silero VAD v5）、`VAD Buffer Size` 与 `Max Concurrent Transcriptions` 会影响批处理体验。关闭批量 VAD 后，本地批量转录会整段识别文件。
- Sona 内置纯 Rust 音频解码引擎，开箱即用支持 WAV、MP3、FLAC、OGG、AAC 与 M4A 常见格式，无需系统预装 FFmpeg。如遇非常规专属封装或小众编码，可在 `设置 > 存储管理` 中配置自定义 FFmpeg 路径作为后备。
- 如果目标是从现成媒体文件导出字幕，`批量转录` 加导出就是最直接的路径。
