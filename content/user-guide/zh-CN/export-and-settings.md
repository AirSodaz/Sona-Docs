这页覆盖工作流的收尾部分：导出成品、做最后的说话人与版本检查、快速找到最常用设置的大致入口，以及理解 `仪表盘`、`诊断`、`备份与恢复`、`自动化` 和通知分别在哪里。

## 如何导出一份成稿

导出前，如果交付或复核需要说话人标签，请先从转录标题栏打开 `说话人校对`。对于已保存且非草稿的转录，如果需要恢复部分差异或整份回退一次批量改写，请先打开 `版本快照`。

1. 点击顶部栏中的 `导出` 按钮。
2. 在 `导出转录` 弹窗中填写 `文件名`。
3. 选择 `导出目录`。
4. 选择输出格式： `SubRip (.srt)`、`WebVTT (.vtt)`、`JSON (.json)`、`Plain Text (.txt)`、`Markdown (.md)`。
5. 选择导出模式： `原文`、`译文`、`双语`。
6. 点击 `导出`。
7. 如果只想按当前导出模式复制纯文本，可以使用 `复制到剪贴板`，不必写出文件。

## 导出之后会得到什么

- Sona 会把转录内容写入你选择的路径和格式。
- `Markdown (.md)` 会把说话人标签保留为加粗标签，方便在 Markdown 编辑器中阅读。
- 如果当前已有译文，可以导出纯译文或双语版本。
- `复制到剪贴板` 会使用当前选择的导出模式，并复制最终分段里的纯文本。
- `译文` 与 `双语` 只有在至少一个分段已经带有翻译文本时才会出现。

## 什么时候该回到 `项目中心`

- 如果你要重新打开、重命名、移动或整理已经保存的录音和导入内容，请回到 [项目中心与收件箱](guide:workspace-projects-and-inbox)。
- 现在项目上下文和 `Inbox` 组织也都统一放在 `项目中心`。

## 按分类组织的设置项

Sona 桌面端的设置侧边栏被划分为 5 个分组：

### 1. 通用 (General)
- `设置 > 常规`：主题、界面语言、字体、开机自启、静默启动（启动最小化到托盘）、更新检查，以及 `诊断` 与 `备份与恢复`
- `设置 > 仪表盘`：全局内容概览、说话人覆盖率与 LLM 使用趋势
- `设置 > 关于`：版本信息、发布说明、开源协议与更新检查

### 2. 识别与语音 (Recognition & Speech)
- `设置 > 输入设备`：麦克风选择、系统音频设备选择、麦克风增强、`保持麦克风激活`、录音时静音
- `设置 > 字幕设置`：实时字幕浮窗行为、外观样式、鼠标穿透与字号大小
- `设置 > 语音输入法`：启用 `语音输入法`、全局快捷键、`按住说话` / `切换模式`、情境预设与就绪状态
- `设置 > 模型设置`：`实时录音模型`、`批量转录模型`、CTC 强制对齐、说话人分离敏感度、`批量 VAD 分割`、`VAD Buffer Size` 与模型管理
- `设置 > 词汇`：划分为 `识别与纠偏`、`提示词与上下文`、`说话人档案` 三个子标签页，支持统一词典（可视化与 YAML 源码双模式）

### 3. AI 与自动化 (AI & Automation)
- `设置 > LLM 服务`：功能模型绑定（支持基于 llama.cpp 的本地 GGUF 模型与基于 aimux 的云端多模型）、思考过程与正文分离、Provider 凭据管理
- `设置 > 自动化`：监控文件夹规则，可在 Sona 运行时自动转录、润色、翻译并导出新媒体文件到指定项目

### 4. 集成与同步 (Integration & Sync)
- `设置 > 云同步`：端到端加密（E2EE）跨设备同步库，支持 WebDAV 与 S3 兼容对象存储（AWS S3、Cloudflare R2、MinIO 等）、主密码、应急恢复密钥与冲突中心
- `设置 > API 服务`：本地 HTTP API 主机、端口、可选 API Key、IP 白名单、REST 转写与 WebSocket 实时流式识别
- `设置 > MCP 服务`：Model Context Protocol 服务桥接配置、端点监控与 Agent 权限开关（允许文稿编辑、破坏性操作、模型管理等）

### 5. 系统与高级 (System & Advanced)
- `设置 > 存储管理`：数据与模型目录概览、热重载存储迁移（无需重启动态迁移目录并带进度提示）、纯 Rust 音频解码与可选自定义 FFmpeg 路径、磁盘分析与清理策略
- `设置 > 快捷键`：实时录音、播放、搜索、项目导航与编辑器快捷键（支持删除线 `Ctrl + Shift + S`）
## 诊断、备份、云同步与消息中心

- 在 `设置 > 常规` 中，可以通过 `诊断` 检查本地转录链路、运行时就绪状态和打包环境。
- 同一页中的 `备份与恢复` 可以导出或导入轻量归档，其中包含配置、项目数据、轻量历史转录与摘要、自动化状态，以及仪表盘 LLM 使用记录。
- 轻量备份会恢复文本历史和摘要，但不会包含原始音频文件；恢复后的条目可能可以阅读和编辑，但没有音频播放。
- `设置 > 云同步` 是独立的端到端加密（E2EE）增量同步系统。文稿与配置离开本机前均由主密码加密，支持应急恢复密钥重置访问，并提供冲突中心裁决多端并发修改。录音音频始终保存在本地机器上，不会上传云端。
- 页面底部提供一次性导入旧版 WebDAV 备份归档的入口；Sona 不再创建新的远端整包备份。
- 顶部消息中心集中管理批量转录、自动化与 LLM 任务，提供实时进度并在批量转录时支持实时取消，配备已完成任务清空菜单；中断的任务也可在其中的恢复中心继续或丢弃。
